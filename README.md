# NCAAF Data Collection

Landscape-mobile data collection console for NCAAF live games.

## Quick start

```bash
npm install
npm run dev
```

Open http://localhost:5173 — pick a fixture, then use the three-panel game console.

## Screens

| Screen | Description |
|--------|-------------|
| **Fixtures** | List of matches — tap to enter a game |
| **Game console** | Scoreboard, Play by Play, and Risk Management panels |

## Interactions

- **Take Control** — toggles red control mode (red border + background, button becomes "Stop Control")
- **Clock** — tap the time to pause/restart; **−** / **+** adjust by 1 second
- **Risks** — tap to toggle (active risks turn red)
